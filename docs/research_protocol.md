## Working title

**Valid Is Not Faithful: Source-Grounded Semantic Verification of LLM-Based HL7 v2–FHIR Transformations**

## Central contribution

FHIRBridge-Bench is a **measurement and verification study**, not primarily a converter study. The intended contribution is a validated, source-grounded instrument for measuring semantic fidelity in HL7 v2 ↔ FHIR transformations generated by deterministic systems and large language models.

## Primary research question

Among structurally valid LLM-generated FHIR → HL7 v2 transformations, how often do outputs contain at least one major semantic-fidelity error when measured by a validated source-grounded verifier?

## Primary hypothesis

The proportion of structurally valid FHIR → HL7 v2 outputs containing at least one major semantic-fidelity error will exceed a pre-registered non-trivial threshold, conditional on the verifier meeting its pre-specified validation criteria against blinded expert adjudication.

The exact threshold will be selected after a pilot and before the confirmatory experiment.

## Primary endpoint

**Valid-but-Unfaithful Rate (VUR):**

> the proportion of structurally valid transformations containing at least one major fabrication, semantic corruption, or required omission.

FHIR → HL7 v2 is the primary stratum. HL7 v2 → FHIR is the control direction.

## Scientific ordering

The study is deliberately ordered as follows:

1. define semantic fidelity;
2. define the projectability contract;
3. define the canonical fact representation;
4. implement independent renderers and lifters;
5. implement the verifier;
6. qualify the verifier as a measurement instrument;
7. freeze the verifier and confirmatory protocol;
8. run model comparisons;
9. perform external validation.

Large-scale LLM inference must not precede verifier qualification.

## Translation directions

### Primary stress direction

**FHIR → HL7 v2**

This direction is treated as a projection problem rather than as the inverse of HL7 v2 → FHIR. Correctness is defined relative to an explicit target message/profile and a projectability contract.

### Control direction

**HL7 v2 → FHIR**

The control direction uses better-specified mappings and permits comparison with standards-based deterministic transformation.

## Ground-truth principle

A deterministic converter output is **not** ground truth.

Primary truth is represented as standard-independent clinical facts plus explicit projectability rules. Generated outputs are lifted back to facts and compared under declared equivalence rules.

## Required safeguards against circularity

- The canonical fact representation must not be derived from the output of the system under test.
- Renderer and lifter implementations must be separated.
- At least two independently implemented reference renderers must be used where feasible.
- External converters may be used as differential comparators, never as unquestioned truth.
- Mapping resources used in model prompts must not become the sole scoring oracle.
- The projectability contract must be versioned and frozen before confirmatory model runs.
- The verifier must be frozen before the sealed expert-validation set is opened.
- Seeded-fault tests support instrument validation but do not replace naturally occurring model errors in expert adjudication.

## Core error classes

1. **Fabrication / translation hallucination** — target clinical content without permissible source grounding.
2. **Semantic corruption** — grounded target content that changes source meaning.
3. **Omission** — required source fact absent from the target.
4. **Licensed normalization** — permitted representation change; not an error.
5. **Licensed derivation** — explicitly permitted derivation; not an error.
6. **Declared representational loss** — information permitted to be lost under the projectability contract; not an error when correctly declared.
7. **Indeterminate** — insufficiently specified or expert-disputed mapping; excluded from the primary endpoint.

Severity is a separate axis from error type.

## Primary measurement set

The main analysis will prioritize a compact metric set:

- Structural validity rate
- Valid-and-Faithful Yield (unconditional companion estimand)
- Valid-but-Unfaithful Rate (primary endpoint)
- Fabrication rate
- Required omission rate
- Semantic corruption rate
- Verifier sensitivity / specificity / PPV / NPV against expert adjudication

Terminology, unit, identifier, temporal, and reference errors are reported as semantic-corruption subtypes rather than independent headline outcomes.

## Candidate system comparison

Core confirmatory arms should remain small:

1. deterministic standards-based baseline;
2. direct structured LLM generation;
3. mapping-aware LLM generation;
4. mapping-aware generation + syntax-validator repair.

A provenance-constrained arm may be retained as a secondary experiment if the project measures claimed versus independently verified grounding.

Hybrid deterministic + LLM transformation is not part of the core confirmatory design unless a specific scientific hypothesis is defined for it.

## Verifier qualification gate

No headline LLM result is interpretable until the verifier passes pre-registered instrument-validation thresholds.

Qualification must include:

- seeded single-fault and multi-fault suites;
- blinded expert adjudication of naturally occurring transformation outputs;
- pre-adjudication inter-rater agreement;
- sensitivity and PPV for major semantic-fidelity errors;
- confidence intervals;
- explicit failure-envelope documentation.

The exact acceptance thresholds will be fixed after pilot calibration and before sealed evaluation.

## Expert validation

Planned structure:

- development/calibration set;
- sealed confirmatory test set;
- two independent primary reviewers per case;
- third adjudicator for disagreement;
- reviewers blinded to model identity, verifier verdict, and claimed provenance;
- agreement reported before adjudication;
- verifier code and contract tagged/frozen before sealed-set evaluation.

## External validation

Public benchmark experiments will use synthetic data. External validation may include:

- MIMIC-IV-FHIR or another governed FHIR corpus, processed locally under its data-use agreement;
- a small local real-world HL7 v2 corpus if obtainable.

Restricted patient-level inputs and outputs will not be released publicly.

## Privacy scope

Privacy is a governance requirement, not a scientific contribution.

- Hosted-model experiments use synthetic data only unless governance explicitly permits otherwise.
- Restricted data remain inside approved infrastructure.
- Provider/model routing, retention settings, logging, and caching must be documented.
- No claim of privacy-preserving AI will be made.

## Cybersecurity scope

Prompt-injection testing is **not part of the core study**. It may be considered later as a supplementary or follow-up robustness experiment only if it does not dilute the primary measurement study.

## Reproducibility

Before confirmatory inference begins, the repository will contain versioned:

- canonical schema;
- projectability contracts;
- target profiles;
- renderers;
- lifters;
- verifier;
- error taxonomy;
- fault-injection library;
- expert-annotation rubric;
- model prompts and configurations;
- statistical analysis plan;
- benchmark manifests and seeds.

## Freeze rule

Protocol v1.0 will be tagged before the confirmatory LLM runs. Any later change affecting scoring, contracts, eligibility, primary endpoints, or statistical testing must be documented as a protocol amendment.
